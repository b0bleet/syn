Use it from anywhere

Plain HTTP, no key needed. A GET answers with the bare label; add ?verbose=1 for probabilities.

# labels, then text; + is a space
curl https://sifty.dev/positive,negative,neutral/The+battery+died+after+two+days

# the same as query parameters, with every label's probability
curl "https://sifty.dev/?labels=billing,technical,sales&text=I+was+charged+twice&verbose=1"

# up to 32 texts in one request
curl https://sifty.dev/ -H 'Content-Type: application/json' \
  -d '{"input": ["Win a free iPhone", "Lunch at noon?"], "labels": ["spam", "not spam"]}'

Verbose and POST responses look like this:

{"model": "Qwen/Qwen3-8B",

Yes/no, choices, and scores

sifty speaks the typesafe-sdk protocol, so its Python client works unchanged. Ask several typed questions about one piece of text in a single call. Any key works on the free tier.

from typesafe_sdk import Choice, Noul, Score, TypeSafeClient

client = TypeSafeClient(api_key="free", base_url="https://sifty.dev", timeout=120)
response = client.system_one(
    state="I was charged twice. Please fix this ASAP.",
    questions={
        "billing": Noul(instructions="Is this ticket about billing?"),
        "tone": Choice(instructions="What is the customer's tone?",
                       criteria={"calm": None, "frustrated": None, "angry": None}),
        "urgency": Score(instructions="How urgent is this ticket?",
                         criteria=["can wait", "this week", "today"]),
    },
)
response.nouls["billing"].noul      # probability of yes
response.choices["tone"].choice     # most likely label
response.scores["urgency"].score    # expected level, 0 to 2

How it works

No text is generated. The answer comes from the model's own probabilities.

Reads probabilities

Your labels become lettered options, and the model's next-token probabilities for those letters become the scores.

Cancels position bias

Every label is scored in every position and the results are averaged. When the orderings disagree, the answer says so.

A real model on a GPU

Qwen3-8B, woken on demand. After a quiet spell the first request takes up to a minute; after that, about half a second.

Limits

Free for everyone, with a daily allowance per IP address so it stays that way.

Daily allowance1,000 units per IP address, reset at 00:00 UTC
What a unit isOne request; a batch counts each text, a System One call each question
Where you standX-RateLimit-Remaining on every response; 429 with Retry-After once it is used up
Per request2 to 26 labels; up to 32 texts per batch; URLs up to 4,000 characters of text
